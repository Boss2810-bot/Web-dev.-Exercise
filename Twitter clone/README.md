
# Twitter Clone UI

This project is a modern, responsive Twitter clone UI built with React and Vite.

## Features
- Sidebar navigation (Home, Explore, Notifications, Messages, Bookmarks, Profile)
- Tweet feed with sample tweets
- Tweet composer
- User profile section
- Modular, accessible, and reusable components
- Styled with CSS Modules

## Getting Started

1. Install dependencies:
   ```powershell
   npm install
   ```
2. Start the development server:
   ```powershell
   npm run dev
   ```

Open [http://localhost:5173](http://localhost:5173) to view the app.

---
This UI is for demonstration purposes and does not include backend or authentication logic.
